## 1. 현재 서비스 진단

### 1-1. 기능 인벤토리 (캡처 기준)

| 영역 | 현재 상태 |
|---|---|
| 분석 입력 | 주소(시/도 → 시/군/구 → 동) 또는 지도 선택, 분석 반경 300/500/900m, 업종 선택(카페·음료, 한식·치킨, 베이커리, 주점·호프, 디저트 등) |
| 분석 결과 | 판단 점수(예: 84/100), 등급(A), 상권 모델명("강남 출퇴근 핵심 상권"), 비슷한 가게 밀도(9.7/10k), 동네와 맞음(82/100), 사람 흐름(18,600), 현장 확인 질문 3개, "다음에 할 일" 체크리스트 |
| 출력·공유 | PDF 저장, 공유 링크 복사 |
| 전환 장치 | **"전문가 검토 요청"** 폼(이름, 연락처, 후보지 링크, 질문, 검토 지역) — 현재 무료 |
| 사용 제한 | 일일 분석 한도 표시(예: 64/100 잔여) — 클라이언트 표시 수준으로 추정 |
| 신뢰 장치 | "공공데이터 기반 1차 검토이며, 카드매출 기반 정밀 예측은 아닙니다" 면책 문구, 쉬운 언어("초등학생도 이해하는 설명") |
| 미비 | 회원가입/로그인 없음, 결제 수단 없음, 가격 페이지 없음, 무료↔유료 사다리 없음 |

### 1-2. 강점 (유료화 관점)

1. **전환 훅이 이미 존재** — "전문가 검토 요청"은 그대로 유료 상품이 될 수 있는 리드 수집 장치다. 결제만 붙이면 가장 빨리 매출이 나온다.
2. **가치 사다리의 1층이 완성됨** — 무료 점수로 신뢰를 만들고, "왜 이 점수인가"의 근거를 유료로 팔 수 있는 구조.
3. **정직한 면책 문구** — "카드매출 기반 정밀 예측은 아닙니다"는 역으로 *정밀 예측 = 유료 상위 상품*이라는 업셀 명분이 된다.
4. **운영자의 신뢰 자산** — 실제 카페(유니컵커피) 운영 + AI 상권분석 특허 출원(10-2025-0121296) + 저서. "직접 가게를 운영하는 사람이 만든 도구"는 경쟁 데이터 기업이 흉내 낼 수 없는 차별점.

### 1-3. 약점 / 유료화 전 반드시 보완할 것

1. 사용량 제한이 서버에서 강제되지 않으면 유료 전환 동기가 약하다 (브라우저 우회 가능).
2. 결제·회원·영수증 등 상거래 인프라 부재.
3. 무료 결과가 너무 완결적이면 돈 낼 이유가 없다 — **무료/유료 경계 재설계 필요**.

## 2. 무엇을 추가해야 비용을 받을 수 있는가 (기능 설계)

### 2-1. 상품 구조: 4단 가치 사다리

```
무료 진단  →  단건 심층 보고서  →  구독(다건 비교)  →  전문가 검토/동행 실사
 (미끼)        (9,900~19,900원)     (월 29,000원~)        (99,000원~50만원)
```

| 단계 | 상품 | 가격(제안) | 포함 내용 | 추가 개발 필요사항 |
|---|---|---|---|---|
| 0 | 무료 진단 | 0원 | 점수·등급·요약 3지표만. 일 3회 | 서버측 한도(IP+계정), 결과 일부 블러 처리 |
| 1 | 심층 보고서(단건) | 9,900~19,900원 | 경쟁점 전체 목록·거리, 시간대/요일 유동 추정, 임대시세 구간, 손익분기 시뮬레이션, 입지 리스크 체크리스트, 워터마크 없는 PDF | 보고서 콘텐츠 확장(공공데이터 추가 연동), 결제, 보고서 영구 보관함 |
| 2 | 구독(프로) | 월 29,000~49,000원 | 무제한 분석, 후보지 N개 나란히 비교, 상권 변화 알림(신규 경쟁점 출현 등), 엑셀 내보내기 | 회원 체계, 후보지 저장/비교 UI, 월 배치 알림 |
| 3 | 전문가 검토 | 99,000원(서면) / 300,000~500,000원(현장 동행) | 48시간 내 서면 검토, 계약 전 리스크 정리, 현장 실사 동행 | **개발 거의 불필요** — 기존 폼에 결제 추가 |

핵심 원칙: **점수(결론)는 무료, 근거(디테일)는 유료.**
현재 무료로 노출 중인 것 중 아래를 유료 영역으로 이동:

- 비슷한 가게 9.7/10k → 무료는 밀도 숫자만, **유료는 경쟁점 실명 목록 + 지도 표시**
- 사람 흐름 18,600 → 무료는 총량만, **유료는 시간대·요일·연령 분해**
- 현장 확인 질문 3개 → 무료 유지(현장으로 보내는 건 신뢰 구축), **유료는 질문별 판단 기준표 추가**

### 2-2. 기술적으로 추가할 것 (우선순위순)

| # | 항목 | 내용 | 공수(1인 기준) |
|---|---|---|---|
| 1 | 결제 | 토스페이먼츠 또는 포트원. 단건은 일반결제, 구독은 빌링키 정기결제 | 1~2주 |
| 2 | 회원/인증 | 이메일+카카오 소셜 로그인. 분석 이력·보고서 보관함 | 1~2주 |
| 3 | 서버측 사용량 제한 | 무료 횟수를 DB에서 차감. 비로그인은 IP 기준 더 적게 | 2~3일 |
| 4 | 유료 보고서 콘텐츠 | 소상공인시장진흥공단 상가업소 API(경쟁점 목록), 서울시 상권분석 데이터(시간대 유동), 부동산원/실거래가(임대 추정), 손익 시뮬레이터(객단가·회전율 입력형) | 4~6주 |
| 5 | 가격 페이지 + 결제 UX | 무료 결과 화면 하단에 잠긴 섹션 미리보기("🔒 경쟁점 12곳 목록 보기") | 1주 |
| 6 | 사업 인프라 | 통신판매업 신고, 이용약관·개인정보처리방침·환불규정, 현금영수증/세금계산서 발행 | 1~2주(행정) |

> 합계: **전문가 검토 유료화만이면 2주 내, 단건 보고서까지 약 2개월, 구독까지 약 3개월** (풀타임 1인 또는 외주 기준).

## 3. 가격을 받는 논리 (Pricing Logic)

### 3-1. 가치 논리 — "창업 실패 보험"

- 외식업 창업 비용은 통상 5,000만~2억 원, 폐업 시 회수 불가 손실이 수천만 원.
- 1~2만 원짜리 보고서는 **총 투자액의 0.02~0.04%로 최악의 입지를 거르는 보험**이다.
- 화면 문구 제안: *"권리금 한 달 치의 1%로, 계약 전에 확인하세요."*

### 3-2. 대안 비교 논리 (앵커)

| 대안 | 비용 | 약점 |
|---|---|---|
| 나이스비즈맵/오픈업 등 | 무료~수만 원 | 범용·표 위주, 외식 특화 해석 없음 |
| 창업 컨설팅 | 회당 수십만~수백만 원 | 비싸고 품질 편차 큼 |
| 프랜차이즈 본사 상권조사 | "무료" | 본사 이해관계 — 출점시키는 쪽으로 편향 |
| **본 서비스** | 0원 → 1.9만 원 → 9.9만 원 | **외식 특화 + 운영자가 실제 카페 대표 + 중립** |

차별화 멘트: "프랜차이즈 본사의 상권조사는 가맹계약이 목적입니다. 우리는 말리는 것도 결론입니다."

### 3-3. 전환 설계 논리

1. **무료에서 멈추지 못하게**: 결과 화면에 잠긴 섹션을 실제 데이터 일부와 함께 노출(블러 처리). "이 동네 경쟁 카페 12곳 중 3곳이 최근 6개월 내 개업 → 전체 목록 보기 🔒"
2. **시점 공략**: 부동산 계약 직전이 지불의사 최고점. PDF·공유링크에 "계약 전 전문가 검토" 버튼을 반복 배치(이미 Review CTA 있음 — 결제만 연결).
3. **한도 설계**: 무료 일 3회로 축소(현 100회는 과다). 횟수 소진 화면이 곧 결제 화면.

## 4. 어디에, 누구에게 제안할 것인가 (판매 채널 설계)

### 4-1. B2C — 예비 외식 창업자 (단건·구독)

| 채널 | 실행 방법 |
|---|---|
| 네이버 카페("아프니까 사장이다" 등 자영업 커뮤니티) | 무료 분석 링크 공유 + 후기 콘텐츠. 직접 광고보다 "내 동네 분석해봤다" 후기 형식 |
| 유튜브 창업/장사 채널 | 채널당 제휴 코드(수익 셰어 20~30%) — 구독자가 곧 타깃 |
| 검색 광고 | "상가 임대", "카페 창업 비용", "OO동 상권" 키워드. 무료 진단으로 유입 후 전환 |
| 창업 박람회(프랜차이즈 창업박람회 등) | 현장에서 즉석 무료 진단 → 전문가 검토 패키지 판매 |

### 4-2. B2B — 반복 구매처 (월 과금·화이트라벨)

| 대상 | 제안 논리 | 상품 형태 |
|---|---|---|
| **상가 전문 공인중개사** | 매물마다 분석 PDF를 첨부하면 매물 신뢰도·계약 전환율 상승 | 화이트라벨 보고서(중개사무소 로고), 월 99,000원 30건 |
| **프랜차이즈 본사** (월드푸드테크협의회·CCFA 네트워크 활용) | 가맹 희망자 출점 검토 표준화, 출점 실패율 감소 | 좌석 라이선스 월 30~50만 원 + 본사 전용 기준 모델 |
| **인테리어·주방설비 업체** | 계약 전 고객에게 분석 제공 → 영업 도구 | 제휴 리드 수수료 |
| **은행·지역 신용보증재단** | 소상공인 대출 심사 시 입지 리스크 참고자료 | 건별 API 과금 |

### 4-3. 공공 — 정부가 대신 돈을 내는 구조 (가장 큰 레버리지)

| 대상 | 프로그램 | 제안 포인트 |
|---|---|---|
| 소상공인시장진흥공단 | **컨설팅 바우처 / 신사업창업사관학교** | 수행기관·컨설턴트로 등록되면 검토 비용을 정부 바우처가 지불. 특허 출원 + 실운영 경력이 등록 심사에 유리 |
| 지자체 창업지원센터(부산 우선) | 청년창업 교육·입지 검토 용역 | 부산시 푸드테크 조례 의견 제출 이력, 지역 연고 활용. "관내 창업자 전원 무료 진단" 형태의 연간 계약 제안 |
| 창조경제혁신센터·창업진흥원 | 예비창업패키지 멘토링 | 멘토 등록 → 멘티에게 도구 보급 |

공공 제안서 핵심 논리: *"폐업률을 낮추는 가장 싼 방법은 개업 전 검증이다. 1건당 N만 원의 진단 비용으로 평균 폐업 손실 X천만 원과 재정 지원 낭비를 예방한다."*

### 4-4. 제안 우선순위 (추천 실행 순서)

1. **즉시(2주)**: 전문가 검토 유료화 — 이미 들어오는 요청에 가격표만 붙인다.
2. **1개월**: 상가 전문 중개사무소 5곳 파일럿(무료 1개월 → 월 구독 전환).
3. **2개월**: B2C 단건 보고서 출시 + 자영업 커뮤니티·유튜브 제휴.
4. **3개월~**: 소진공 바우처 수행기관 등록 절차 + 지자체(부산) 제안서 제출.
5. **6개월~**: 프랜차이즈 본사 라이선스(자사 유니컵커피 가맹 검토에 먼저 적용해 레퍼런스化).

## 5. 목표 수치와 검증 지표 (KPI)

| 지표 | 초기 목표 | 비고 |
|---|---|---|
| 무료 분석 → 결제 전환율 | 2~5% | 잠긴 섹션 클릭률로 선행 측정 |
| 전문가 검토 요청 → 결제 전환 | 30%+ | 이미 의향 있는 리드라 높게 잡음 |
| 객단가 | 단건 1.5만 / 검토 10만 | |
| 월 손익분기 | 고정비(서버+API ≈ 20만 원) 기준 단건 14건 또는 검토 2건 | 인건비 제외 |
| B2B 1곳 가치 | 월 10~50만 원 | B2C 60건과 동일 — 영업 우선순위 근거 |

## 6. 리스크와 대비

1. **데이터 정확도 클레임** → 면책 문구 유지 + "현장 확인 질문" 프레임 강화(도구는 보조, 판단은 현장). 환불 규정 명문화.
2. **대형 경쟁사(나이스, 오픈업) 무료 공세** → 범용 데이터 싸움 회피, "외식 특화 + 실제 운영자 + 전문가 검토"라는 사람 결합 모델로 차별화.
3. **공공데이터 갱신 지연** → 보고서에 데이터 기준일 명시.
4. **법무** → 통신판매업 신고, 위치기반서비스 해당 여부 검토(주소 기반 조회는 일반적으로 비해당이나 확인 권장).
